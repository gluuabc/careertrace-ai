# Resume Revision

Compare confirmed profile/document facts with the selected target. Preserve
meaning and never invent metrics, achievements, titles, technologies, or dates.
Unsupported improvements must be marked as needing user input. Save structured
changes as a draft and clearly state that they were not applied.

Read `revision_rules.md` for the complete evidence rules.
