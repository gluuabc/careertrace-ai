# Legacy Streamlit Community Cloud Notes

Streamlit Community Cloud was an earlier deployment checkpoint. It is not the
current public judge endpoint and should not be cited as the submission's
deployment environment.

Current deployment configuration, migration prerequisites, public URL, and
verification steps are maintained in [`DEPLOYMENT.md`](DEPLOYMENT.md).

The reusable Streamlit secrets shape remains available in
[`streamlit-secrets.example.toml`](streamlit-secrets.example.toml) as a
configuration reference. It contains placeholders only and is not evidence of
an active Streamlit Community Cloud deployment.
